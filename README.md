# 🎮 Tetris Game Demo

A simple Tetris game developed using **C# and Windows Forms**.  
The project demonstrates object-oriented programming, game logic, keyboard controls, collision detection, piece rotation, line clearing, and score management.

## 📌 Project Overview

This project is a desktop-based Tetris game where different Tetris pieces are randomly generated and fall inside a 10 × 20 game board.

The player can:

- Move pieces left and right
- Move pieces downward
- Rotate pieces
- Instantly drop pieces
- Clear completed rows
- Earn points by clearing lines
- Continue playing until the board is full

## 🛠️ Technologies Used

- **C#**
- **.NET**

## 🎮 Game Controls

| Key | Action |
|-----|--------|
| ⬅️ Left Arrow | Move piece left |
| ➡️ Right Arrow | Move piece right |
| ⬇️ Down Arrow | Move piece down |
| ⬆️ Up Arrow | Rotate piece |
| Space | Drop piece instantly |

## 🧩 Tetris Pieces

The game supports all seven standard Tetris pieces:

- I
- J
- L
- O
- S
- T
- Z
